# Чаршафчето — интерактивен e-commerce прототип

Това е работещ front-end прототип без външни зависимости. Данните за продуктите, количката, любимите и демо поръчките се пазят в `localStorage` на браузъра.

## Стартиране

Най-лесно:

```bash
python3 -m http.server 8080
```

След това отвори `http://localhost:8080`.

Може и просто да се отвори `index.html`, но локален HTTP сървър е по-надежден.

## Включено

- Начална страница, вдъхновена от логото на Чаршафчето
- Продуктов каталог, категории, търсене и филтри
- Продуктова страница
- Любими
- Количка
- Демо checkout и създаване на поръчка
- Клиентски профил: поръчки, любими, лични данни, адреси
- Админ портал: dashboard, продукти, поръчки, клиенти, отстъпки, настройки
- Добавяне, редактиране и изтриване на продукти в админ панела
- Промяна на статус на поръчка
- Responsive дизайн за desktop/tablet/mobile

## Важно

Това е визуален и функционален MVP прототип. За production версия следва да се заменят локалните данни с реален backend/database, истинска authentication система, плащания, Speedy/Econt интеграции, email известия, GDPR/consent, audit log, backups и production security.
